# MVP 范围：0.2.0

单指标、多归档；对齐采样；四种聚合；缺测阈值；固定容量覆盖；区间查询及覆盖元数据；有界二进制快照解析与续写；显式 counter32 速率转换。

本版增加 Native 文件保存/加载与运行样例，提供独占暂存、文件同步及替换流程，测试缺失文件、损坏文件、临时文件冲突和读取限额；加入实际 RRDtool 子集对照脚本及百万次更新基准。

对应申报书三项工作：文件适配见 docs/STORAGE.md；成熟实现对照见 docs/RRDTOOL.md；工程测试与空间/时间基准见 docs/BENCHMARK.md 和 CI。对照仅证明已测的对齐 GAUGE 子集，不代表完整 RRDtool 兼容。

仍保持单写者、严格对齐采样边界，不实现任意插值、分布式存储、事务或断电一致性。性能测量是单次环境结果；空间指标为保留条数及快照字节，不是进程峰值内存。

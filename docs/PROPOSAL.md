# MoonRRA 项目申报书（待本人核对）

**项目名称：** MoonRRA——MoonBit 固定容量多分辨率时序归档库。

**项目简介与方向：** 面向监控与设备采样的可嵌入基础库，以 MoonBit 实现时间桶聚合、循环覆盖及状态保存，为持续增长的指标提供可配置的保留周期和空间上限。

**通用性：** 对外提供独立的创建、更新、区间查询、覆盖信息及快照接口；核心不依赖网络服务或外部数据库，可被 Native、JS、Wasm 和 Wasm-GC 应用复用。

**使用场景：** ①服务每分钟记录内存指标，查询小时汇总；②设备采集温度，缺测保留未知状态并在恢复快照后继续归档；③网络接口累计字节转换为速率，保留近期数据与较长期峰值。

**已有基础：** 已实现严格对齐的时间采样、平均/最小/最大/最后已知值聚合、缺测阈值、固定容量环形存储、二进制快照与完整性检查，并提供三个可运行样例。

**拟完善功能：** 增加对齐采样子集的成熟实现对照测试；完善文件存储适配及快照往返示例；补充长期运行基准、错误输入测试、中文接口说明与 Mooncakes 发布验证。以明确的单指标、多归档核心为范围，不承诺分布式数据库或 RRDtool 全功能兼容。

**技术路线与验收目标：** 每层独立配置聚合倍数、容量及已知数据阈值；旧数据按时间覆盖。以批处理参考模型、时间边界、长间隔、快照续写与异常输入测试验证正确性，持续集成执行检查、构建、测试及样例。

**原创及参考关系：** 独立 MoonBit 实现，参考 [RRDtool](https://oss.oetiker.ch/rrdtool/doc/rrdcreate.en.html) 的循环归档概念，未移植其源码。项目采用 Apache-2.0。与现有统计、查询及无损时序压缩库相比，本项目聚焦有界容量和多级有损聚合；详细比较见仓库查重文档。

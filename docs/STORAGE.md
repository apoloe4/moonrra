# Native 文件存储

运行 `moon run examples/files --target native`。示例创建独立临时目录，在磁盘保存尚未完成的聚合桶，重新加载、补充采样、替换保存，再次打开并断言均值为 15；结束后清理自己创建的临时目录。

调用方导入 `apoloe4/moonrra/storage`；在 async 函数中执行 `save(store, path)` 与 `load(path, max_bytes=...)`。此包仅支持 Native，依赖 Apache-2.0 的官方 `moonbitlang/async@0.22.9` 文件接口；归档核心仍无外部运行时库依赖。

保存使用同目录 `path + ".tmp"` 独占创建，写完并同步文件后重命名替换目标。已有临时文件会报错，不覆盖其他写入者。每个路径应有单一写入者；异常退出遗留的临时文件需应用确认归属后处理。未同步目录元数据，因此不承诺断电一致性或事务。

加载在同一文件描述符上先检查大小、再有界读取，最多 24,004,000 字节；解码继续检查校验、配置和状态。正在被其他进程改写的文件不属于支持的使用方式。
